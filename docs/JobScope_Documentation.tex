\section{Getting Started}
\label{sec:start}

\subsection{Prerequisites}
\begin{itemize}[leftmargin=2em]
  \item Python 3.11+ (developed on 3.14).
  \item \href{https://ollama.com/download}{Ollama} running locally with a
        model pulled (default \tool{llama3.1}).
  \item Optional: Gmail OAuth client secret (for the job-alert fallback).
  \item Optional: GitHub personal access token (public reads work without
        one; a token raises the 60~req/h anonymous rate limit).
\end{itemize}

\subsection{Installation}
\begin{lstlisting}[language=PowerShell]
git clone <this-repo>
cd jobscope
python -m venv .venv
.\.venv\Scripts\Activate.ps1            # bash: source .venv/bin/activate
python -m pip install -r requirements.txt
pip install -r requirements-dev.txt     # pytest + pyflakes
python -m playwright install chromium   # for browser-mode scraping

Copy-Item .env.example .env             # then edit your values
ollama pull llama3.1
\end{lstlisting}

Key pinned dependencies: \file{langgraph} 1.2.11, \file{langchain-core}
1.6.2, \file{langchain-ollama} 1.1.0, \file{mcp} 1.30.0,
\file{langchain-mcp-adapters} 0.3.2, \file{fastapi} 0.116.1,
\file{uvicorn} 0.53.0, \file{chainlit} 2.8.0, \file{pypdf} 6.19.0,
\file{pymupdf} 1.28.2, \file{rapidocr} 3.9.2, \file{onnxruntime} 1.30.0,
vendored \file{Scrapling} 0.4.15 (\code{[fetchers]} extra).

\subsection{Gmail OAuth setup}
\begin{lstlisting}[language=PowerShell]
python gmail_login.py
\end{lstlisting}
One-shot interactive consent (\code{gmail.readonly} scope) against
\file{client_secret.json}; writes \file{gmail\_oauth\_token.json}. The MCP
Gmail server reuses and auto-refreshes this token. SMTP
(\env{SMTP\_HOST} $\ldots$) is configured separately for account
verification and password-reset emails.

\subsection{Launch options}
\begin{center}
\begin{tabular}{@{}ll@{}}
\toprule

\textbf{Invariants:}
\begin{itemize}[leftmargin=2em]
  \item One compiled graph: \code{create\_agent()} is shared by dashboard,
        chat UI, and CLI.
  \item MCP servers are \emph{stdio subprocesses}, not network services.
        Only ports 8000 (dashboard) and 11434 (Ollama) are open locally.
  \item Every job source ends with a machine-readable
        \code{###JOBS\_JSON###} payload (deck feed for the UI, structured
        status for the router).
  \item Filtering, routing, and tailoring are deterministic code; the LLM
        generates prose and can be bypassed entirely.
\end{itemize}

\section{The LangGraph Agent (\file{agent.py})}
\label{sec:agent}

\subsection{AgentConfig}
Dataclass centralising runtime behaviour. Environment-backed defaults come
from \code{load\_config()}:

\begin{center}
\begin{tabular}{@{}lll@{}}
\toprule
\textbf{Field} & \textbf{Default} & \textbf{Notes}\\
\midrule
\code{model} & \code{llama3.1} & \env{OLLAMA\_MODEL}\\
\code{num\_ctx} & 8192 & \env{OLLAMA\_NUM\_CTX}\\
\code{target\_role} & Junior Data Analyst\ldots & \env{TARGET\_ROLE}\\
\code{target\_roles} & \code{[]} & multi-select; first entry drives the query\\
\code{days\_back} / \code{max\_results} & 60 / 10 & \env{JOB\_DAYS\_BACK}, \env{JOB\_MAX\_RESULTS}\\
\code{skills} / \code{resume\_text} & \code{[]} / \code{""} & from CV upload\\
\code{remote\_only} & \code{False} & legacy flag; work-mode chips win\\
\code{work\_modes} / \code{countries} & \code{[]} & active filters\\
\code{regions} & \code{[]} & retired; kept for old profiles\\
\code{preferred\_cities} / \code{exclude\_locations} & \code{[]} & \\
\code{role\_suggestions} / \code{github\_url} & \code{[]} / \code{""} & \\
\code{summary\_mode} & \code{template} & \env{AGENT\_SUMMARY\_MODE} (\code{template}$\mid$\code{llm})\\
\code{seen\_scope} & \code{""} & \code{"u\{user\_id\}"}; never shown to the model\\
\bottomrule
\end{tabular}
\end{center}

\subsection{State and nodes}
\code{AgentState(MessagesState)} plus \code{fallback\_used: bool}.

\begin{description}[leftmargin=6.2em, style=nextline]
  \item[\nodepill{agent}] Fresh hunt $\rightarrow$ emits one
        \code{AIMessage} with parallel tool calls (zero inference).
        Afterwards, \code{template} mode renders the answer in code from the
        \code{###JOBS\_JSON###} payload; \code{llm} mode invokes an unbound
        \code{ChatOllama} on a trimmed context (tool dumps removed via
        \code{RemoveMessage}).
  \item[\nodepill{tools}] Prebuilt \tool{ToolNode}; parallel calls run
        concurrently.
  \item[\nodepill{prep}] Winner selection in code (boards if non-empty,
        else filtered Gmail); builds the summary payload with
        \code{###JOBS\_JSON###}.
  \item[\nodepill{fallback}] Legacy sequential path; pulls Gmail senders in
        parallel under a 120\,s \code{asyncio.wait\_for}.
\end{description}

\subsection{Routing}
\code{route\_after\_tools} (in order):
\begin{enumerate}[leftmargin=2.2em]
  \item \code{fallback\_used} set $\rightarrow$ \code{agent}.
  \item Any Gmail/email \code{ToolMessage} present $\rightarrow$ \code{prep}.
  \item User named one board $\rightarrow$ \code{prep}.
  \item Latest scraper result contains a blocked marker $\rightarrow$
        \code{fallback}.
  \item Else $\rightarrow$ \code{agent}.
\end{enumerate}

Blocked markers (prose fallback; structured payload takes precedence):
\begin{lstlisting}
"all boards were blocked", "captcha", "http 403", "fall back",
"no job links", "couldn't extract", "request failed", "js-rendered"
\end{lstlisting}

\subsection{Query construction}
\code{search\_query\_from(cfg)}: role reduced by \code{\_board\_role\_phrase}
(aside stripping, separator splits, qualifier drops, typo fixes
\code{devloper}$\rightarrow$\code{developer} $\ldots$), then up to two CV
skills appended (multi-word first; substrings/near-duplicates skipped);
never empty. \code{board\_tool\_args} adds location
(\code{filters.boards\_location}), \code{remote\_only}, normalized
work-modes/countries, \code{seen\_scope}, and \code{board} when named.

\subsection{MCP runtime}
\code{create\_runtime()} builds one \code{MultiServerMCPClient} with three
stdio servers launched via \code{sys.executable}:

\begin{center}
\begin{tabular}{@{}lll@{}}
\toprule
\textbf{Key} & \textbf{Script} & \textbf{Env forwarded}\\
\midrule
\code{github} & \file{mcp\_server\_github.py} & \env{GITHUB\_TOKEN} if set\\
\code{gmail} & \file{mcp\_server\_gmail.py} & all \env{GMAIL\_*}\\
\code{indeed\_scraper} & \file{mcp\_server\_indeed\_scraper.py} & none\\
\bottomrule
\end{tabular}
\end{center}

Tool discovery costs $\sim$3.4\,s: the dashboard caches the runtime for the
app lifetime and agent bundles per \code{(user\_id, profile\_id)}.
\code{AgentBundle.reconfigure(cfg)} rebuilds the graph while reusing the
runtime.

\section{Filtering Rules (\file{filters.py})}
\label{sec:filters}

All rules are pure functions shared by scraper and agent.

\begin{description}[leftmargin=6.4em, style=nextline]
  \item[SENIORITY\_FILTER] Title+location match: senior, lead, principal,
        staff, architect, director, manager, vp, vice president, chief,
        head of. \emph{Never} the company name.
  \item[EXPERIENCE\_FILTER] $\geq$5-year requirements with lookbehinds
        sparing \emph{less than / fewer than / under / up to / max / to};
        digit-hyphen guard spares \emph{0-2 years}.
  \item[INDIA\_TOKENS] Indian cities/states + \emph{Remote-India}; WFH
        exempt, India-scoped remote (\emph{remote-india}, \emph{wfh-india})
        checked before the exemption.
  \item[Work modes] \code{WORK\_MODES = \{remote, wfh, hybrid, onsite\}};
        \code{listing\_work\_modes} reads explicit statements only;
        unstated arrangements kept at search time.
  \item[Countries / regions] $\sim$84 canonical countries with aliases and
        region membership; blank location dropped when a filter is active;
        \emph{worldwide} matches everything. Regions retired from the UI.
  \item[keep\_job] Master gate: $\pi(j)$ = not senior $\wedge$ not 5+yr
        $\wedge$ (not India-tied or WFH-exempt) $\wedge$ mode $\wedge$
        country $\wedge$ valid http(s) link.
\end{description}

Supporting APIs: \code{detect\_board} / \code{canonical\_board} (9 board
aliases), \code{role\_synonyms\_for} / \code{related\_roles} ($\sim$30
synonym families), \code{normalize\_work\_modes} / \code{normalize\_countries}
/ \code{normalize\_cities}, \code{boards\_location} (builds the location
string boards receive), \code{gmail\_search\_plan} (account/sender pairs,
budget 3).

\section{MCP Tool Servers}
\label{sec:mcp}

Each server declares tools with \code{@mcp.tool()} and runs
\code{mcp.run(transport="stdio")}.

\subsection{\file{mcp\_server\_indeed\_scraper.py}}
\tool{search\_job\_boards(query, location="Remote", remote\_only=True,
board=None, work\_modes=None, regions=None, countries=None,
seen\_scope="")} $\rightarrow$ human status lines + \code{###JOBS\_JSON###}.

\begin{itemize}[leftmargin=2em]
  \item Nine boards; default sweep excludes Naukri, Glassdoor, Foundit
        (\code{NOT\_DEFAULT}); \code{board="linkedin"} (or an alias)
        restricts the sweep.
  \item \code{GLOBAL\_DEADLINE = 40\,s}; one thread-pool worker per board;
        stragglers \emph{blocked (timed out)}; pool cancelled without
        waiting.
  \item Failed boards cached 90\,s (\code{BLOCK\_CACHE\_SECONDS}).
  \item Thin results ($<12$) trigger one sibling-role widening sweep
        (\code{[ALSO]} line).
  \item Dedupe on \code{(title.lower(), link)}; \code{MAX\_JOBS = 20}
        returned; ranking de-ranks repeats, never drops them.
  \item Seen-memory: 400 links $\times$ 16 LRU scopes;
        \code{forget\_scope("u\{id\}")} called by dashboard reset.
  \item Manual wall hook: on probe exception, if
        \code{JOBSCOPE\_MANUAL\_WALL=on}, \code{manual\_verify} opens a
        visible browser and results re-enter the same filter pipeline.
  \item Payload keys: \code{sources}, \code{source\_detail},
        \code{blocked}, \code{blocked\_reasons}, \code{no\_matches},
        \code{boards\_worked}, \code{widened\_to}, \code{total},
        \code{fresh}, \code{repeats}, \code{remote\_only},
        \code{work\_modes}, \code{regions}, \code{countries},
        \code{jobs[]}.
\end{itemize}

\subsection{\file{mcp\_server\_gmail.py}}
\begin{itemize}[leftmargin=2em]
  \item \tool{sync\_gmail\_cache(days\_back=3650, account=0)} --- Gmail API
        over OAuth; default syncs both mailboxes;
        \code{from:"sender" after:YYYY/MM/DD} queries; raw messages parsed
        and upserted into \file{gmail\_cache.db}; 403/429 retried with
        exponential backoff (4 tries).
  \item \tool{search\_job\_emails(sender="", days\_back=60,
        max\_results=10, account=0, query="", resync\_if\_stale=True)} ---
        answers from cache; auto-resync when stale ($>$1\,h); over-fetch
        then \code{diverse\_listings} round-robin by sender.
  \item Parsing: footer truncation, tracking-param stripping, multi-listing
        split around view-job/apply anchors, best-link ranking, body cap
        1200 chars, title cap 90.
\end{itemize}

\subsection{\file{mcp\_server\_github.py}}
\begin{itemize}[leftmargin=2em]
  \item \tool{list\_github\_repos(github\_url\_or\_username)} ---
        \code{GET /users/\{u\}/repos?per\_page=100\&sort=updated};
        forks filtered; PAT optional.
  \item \tool{get\_repo\_readme(github\_url\_or\_username, repo\_name)} ---
        base64-decoded README capped at 3000 chars.
\end{itemize}

\section{Resume Pipeline}
\label{sec:resume}

\subsection{CV intake (\api{POST}{/api/resume})}
Multipart upload $\leq$8\,MB. Extraction tiers: pypdf (PDF), docx2txt,
striprtf, plain decode; if $<$200 alphabetic characters survive, Tier-2 OCR
(PyMuPDF 150\,dpi render + RapidOCR ONNX, 4 pages / 45\,s / conf $\geq$0.55
defaults). Then: \code{extract\_skills} (\env{RESUME\_EXTRACT\_MODE=strict}
takes only literal CV keywords), \code{suggest\_roles} (60-role rubric),
\code{infer\_location}, \code{detect\_links} (GitHub/LinkedIn). Each upload
creates and activates a fresh profile.

\subsection{BM25 retrieval (\file{rag\_store.py})}
Okapi BM25 ($k_1=1.5$, $b=0.75$) over 260-char bullet/paragraph chunks
(independent units, no greedy packing). Tokenizer folds
\code{c++}$\rightarrow$\code{cpp}, \code{.net}$\rightarrow$\code{dotnet}
$\ldots$, strips a short stop list, light-stems trailing \code{s}
(length $>$4). Storage: \code{rag\_documents} rows in \file{users.db}
($\leq$400\,000 chars/doc). \code{retrieve(uid, query, k=8)} returns
score-positive top-$k$ chunks with provenance
\code{doc\_name\#index}.

\subsection{Generation (\file{resume\_generator.py})}
\code{build\_resume(cfg, job, desc, github\_url, rag\_hits, ...)}
$\rightarrow$ \code{(latex, filename)}:

\begin{enumerate}[leftmargin=2.2em]
  \item Posting text $P=$ desc $\oplus$ role $\oplus$ company (CV
        deliberately excluded from the ranking query).
  \item Skill groups reordered by 49-term posting lexicon hits; never
        deleted or added.
  \item Experience/Project bullets stably reordered within each entry by
        BM25$(P,\cdot)$; whole spans move; chronology untouched.
  \item Objective from CV summary (or synthesised strictly from CV lines)
        + targeting line seeded by top matched skills.
  \item Optional GitHub projects merged after CV projects
        (\code{\_merge\_github\_projects}, alphanumeric-normalized
        dedupe).
  \item ATS template: 10\,pt article, \code{\textbackslash section*}
        headings, single column, no tables, accent \texttt{1F4E79},
        \code{\textbackslash heading}/\code{\textbackslash subheading}
        macros; \code{\_lx} escapes; \code{\_ascii\_fold} maps unicode
        symbols.
  \item \code{tex\_to\_html}: regex preview without a TeX install.
\end{enumerate}

JD resolution priority: pasted $\rightarrow$ carried $\rightarrow$ fresh
\file{job\_desc} cache $\rightarrow$ \code{desc\_snippet(link)}; a
background fetch (\code{job\_desc.ensure}, 2 Chromium workers, 24\,h TTL,
URL-normalized shared cache) always runs and the modal polls
\api{GET}{/api/resume/desc}.

\subsection{ATS score (\file{ats\_score.py})}
$S=\sum_c w_c s_c$, clamped $[0,100]$: contact 12, sections 14, structure
16, dates 16, keywords 26 ($\sqrt{\text{coverage}}\times 26$, spread
damp), evidence 16. Bands: $\geq$85 strong, $\geq$70 good, $\geq$55 fair,
else weak. Accepts \LaTeX{} or HTML (identically normalised). Returns
\code{total, band, breakdown, issues, hits, missing, keyword\_total}.

\subsection{GitHub projects (\file{github\_projects.py})}
\code{find\_projects(url\_or\_username, jd\_text, max\_projects=3)}:
username from CV; list repos (forks/archived/mirror-like filtered); score
$=2.0\times$ shared JD-vocabulary terms $+$0.5 if described; fetch only
matching READMEs (24\,h disk cache in \code{.github\_cache/}); a bullet is
emitted only if summary and README share $\geq1$ tech term
(\code{\_REPO\_TERMS}). Rate-limit errors degrade to empty, never fail the
resume.

\section{Manual Wall Solving (\file{manual\_verify.py})}
\label{sec:manual}

\code{JOBSCOPE\_MANUAL\_WALL}:
\begin{itemize}[leftmargin=2em]
  \item \code{auto} --- enabled iff a display exists (always on
        Windows/macOS; needs \env{DISPLAY}/\env{WAYLAND\_DISPLAY} on Linux).
  \item \code{on} --- forced; also allows inline solving during a running
        search (never on \code{auto}).
  \item \code{off} --- disabled.
\end{itemize}

Flow: \code{start(board, query)} $\rightarrow$ daemon thread opens visible
Chromium (persistent \code{.browser\_profile}; resources/ads
\emph{not} blocked, because a captcha widget is an image) $\rightarrow$
polls every 1.5\,s until cleared or deadline $\rightarrow$ page considered
cleared only when the wall detector is false \emph{and} the board's parser
returns rows $\rightarrow$ listings re-enter the standard filter pipeline.
Job states: \code{starting $\rightarrow$ waiting $\rightarrow$ done $\mid$
blocked $\mid$ failed}; bounded to 50 concurrent jobs.

\section{Job Description Fetch (\file{job\_desc.py})}
\label{sec:jobdesc}

Two-tier cheapest-first: HTTP impersonation, then browser
(\code{network\_idle=False} --- posting pages are $\sim$8\,s vs 131\,s with
idle waits). Never raises; total failure stores an empty row so the wall is
not re-attacked until TTL. Selectors per board (LinkedIn, Indeed,
Greenhouse, Lever, Ashby, Workable, generic); wall-marked text is never
cached as a description. Cache: \code{job\_desc\_cache} table, 24\,h TTL,
URL-normalized keys (scheme/host case, fragments, tracking params, sorted
query). Async facade: \code{status\_of} / \code{ensure} (2-worker pool,
one in-flight fetch per URL).
